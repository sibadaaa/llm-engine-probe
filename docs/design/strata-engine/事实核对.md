## 1. 定位与版本

* **C/C++ MoE 推理引擎**（部分复用 [llama.cpp/ggml](https://github.com/Niko1221/Strata)），MIT 许可，无遥测。
* 核心机制：MoE 专家三层驻留——GPU 显存（最常用 ~4,000 experts）→ 页锁内存（全部 experts）→
  NVMe 查找表；MTP 投机解码（1.6–1.8×）；GDN 线性注意力（decode 每 token O(1)，decode 速度对上下文长度平坦）。
* 版本：App **v0.2.2** / engine **0.1.47**（核对时点）。版本节奏快，适配结论按机制写、按版本核对。

## 2. 模型与量化包（`MODEL` 键的引擎语义）

| 模型 | 说明 |
|---|---|
| Qwen3.8-Flash-Next | 主线 125B；量化包 `q2_0` / `iq2_xs` / `iq3_xxs` / `iq3_s` / `q8_0` 等 |
| Coder / Swift 1.5 | 代码特化 / 短思考微调；Gyro-S / Gyro-M 为第三方最小包（27.6 / 35 GB） |
| NVFP4 | NVIDIA 4-bit 包（需 ~80 GB 内存保全部 experts） |
| Qwen3.6-35B-A3B | 小模型，支持并发与图片 |
| **Xolotl fork 系** | DeepSeek-V4.1-Flash（552B，RTX 4090+90GB RAM ~27 tok/s）、GLM-5.3-Flash、Qwen3.8-27B |

**对本工具的语义**：`MODEL` 在 vLLM 是权重目录路径，在 Strata 是 **pack 名或本地 GGUF 目录**。
引擎模板（`hosts/engine/strata.env`）负责把 `MODEL` 换成 pack 名（如 `q2_0`）。

## 3. 平台与资源

| 项 | 事实 |

## 4. 安装与启动（host 模式对接面）

三条安装途径（同一引擎、同一模型）：

1. **桌面 App**：releases 下载（`.exe` / `.AppImage` / `.dmg`），内置引擎。
2. **Terminal `strata` 命令**：`curl -fsSL .../install.sh | sh` 装到用户目录；然后
   `strata launch`（交互向导：模型/上下文/图片/访问权）或
   `strata launch --model q2_0 --yes --no-tui`（脚本/agent 无交互）；配套
   `strata launch --plan|--status|--stop`、`strata monitor --url`、`strata update`、
   `strata doctor`、`strata connect`。
3. **源码**：`START-HERE.bat` / `./setup.sh`；在检出目录装 `.venv/`、`engine/`、`third_party/`，
   模型在 `models/`。可选 `--calibrate`（15–30 分钟调优）。

数据与配置落点：`%APPDATA%\Strata\settings.json` 或 `~/.config/strata/settings.json`；
`--data-dir` 可改。每模型配置文件 **`strata-<model>.json`**（`args` 数组 = 引擎 CLI 参数，
`env` 块 = `STRATA_*` 环境变量，另有 sampling 默认、`aliases`、`reasoning_budget_tokens` 等）。

**服务默认端口 8080**（`http://127.0.0.1:8080`）；`START-HERE.bat --port 8081` 有据可查；
⚠️ `strata launch` 是否有 `--port` flag 未在已核对文档中确认（TERMINAL_LAUNCH.md 待核）——
不确认前，host 模板用 `HOST_SERVE_ENTRYPOINT` 显式覆盖入口并传端口。
**访问控制**：默认仅本机；`strata launch --access lan` 生成 API key（`--no-api-key` 裸奔有告警）；
带 key 时元数据端点也要求鉴权。

## 5. HTTP API 面（探针对接核心）

| 端点 | 事实 | 对探针的意义 |
|---|---|---|
| `POST /v1/chat/completions` | OpenAI 兼容，流式/非流式，tools | `probe http` 主路径，直接可用 |
| `POST /v1/completions` | **未提供**（上游端点表没有它） | `PROBE_ENDPOINT=completions` 必须拒绝（无 `api.openai-completions` cap） |
| `POST /v1/messages` / `/v1/responses` | Anthropic / OpenAI Responses | 本工具不使用（记录即可） |
| `GET /v1/models`、`/models` | 只列**已加载**模型；未知 model 名对元数据端点 404 | `status.sh` 与预检可用；`SERVED_NAME` 建议 `strata`（chat 端任意名都答，但统一用已加载名最稳） |
| `GET /health` | 存在 | 就绪探测 |
| `GET /props` | chat template 能力（`chat_template_caps`）、上下文上限、**引擎版本**（"when available"） | hostcheck 元数据兜底；模型能力展示 |
| `GET /status`、`/slots` | 当前动作（reading the prompt / answering）、批槽位 | 排障用，本工具暂不采集 |
| `GET /metrics` | **默认返回 JSON**（监控页数据）；带 `Accept: text/plain` / `application/openmetrics-text` 或 `?format=prometheus` 才返回 Prometheus 文本 | **关键坑**：探针抓取与就绪轮询都要带 `?format=prometheus`（F1 的 `ENGINE_METRICS_FETCH_SUFFIX`） |
| `GET /metrics/prometheus` | llama.cpp/llama-server 指标名 | 备用面，暂不接 |
| `GET /mcp` | MCP 服务器状态 | 不接 |

模型名宽松度：README 说 OpenAI 兼容端点"any API key, any model name"；DETAILS 说元数据端点
未知 model 404。探针统一用 `SERVED_NAME=strata` 规避歧义。

## 6. `/metrics` 指标清单（Prometheus 文本格式）

**vLLM 同名指标**（`metrics.vllm-named` cap 成立的依据，`probe/metrics_probe.py` 解析层直接复用）：

* 计量：`vllm:num_requests_running` / `vllm:num_requests_waiting`、token 与 request 计数器、
  `vllm:prefix_cache_queries_total` / `vllm:prefix_cache_hits_total`、
  `vllm:spec_decode_num_draft_tokens_total` / `vllm:spec_decode_num_accepted_tokens_total`、
  `vllm:kv_cache_usage_perc`
* 直方图：`vllm:time_to_first_token_seconds`、`vllm:inter_token_latency_seconds`、
  `vllm:e2e_request_latency_seconds`

**缺失的 vLLM 指标**（探针需按缺项容错，`stage_table` 已有 `available=False` 行）：
`vllm:request_queue_time_seconds` / `request_prefill_time_seconds` / `request_decode_time_seconds` /
`request_inference_time_seconds` / `request_time_per_output_token_seconds` 等 5 个生命周期直方图、
`vllm:cache_config_info`（**就绪轮询默认正则匹配不到它，必须换 `ENGINE_READY_METRIC`**）、
kv_block_* 系、preemptions、per-request spec 分布。

**`strata:` 专有指标**（F3 可选采集面）：`strata:live_state{state}`、`strata:live_tok_s`、
`strata:live_prefill_tok_s_mean`、`strata:live_prompt_read`、`strata:engine_max_context`、
`strata:totals_prompt_seconds_total` / `_decode_seconds_total`、`strata:last_hit_rate`（专家缓存命中率）、
`strata:last_decode_tok_s`、硬件面 `strata:gpu_util` / `gpu_mem_used_bytes` / `gpu_mem_total_bytes` /
`gpu_temp_celsius` / `gpu_power_watts`（带 `gpu` label）/ `cpu` / `ram_used_bytes` / `ram_total_bytes`。
缺失值**不出样本**（不是 0）。抓取鉴权与 OpenAI 端点同（Bearer）。

## 7. 思考 / 投机解码 / 并发语义（压测参数相关）

| 项 | 事实 | 探针参数影响 |
|---|---|---|
| 思考等级 | `none/low/medium/high`；默认 **high**；OpenAI 走顶层 `reasoning_effort`（也认 `reasoning:{}`、`chat_template_kwargs.enable_thinking`）；流式以 **`reasoning_content`** 增量输出（Anthropic 为 thinking blocks） | `http_probe` 的 delta 兼容已覆盖 `reasoning_content`；注入的 `chat_template_kwargs.reasoning_effort` 可能被忽略（无害），F3 可改注入顶层 `reasoning_effort` |
| `max_tokens` 语义 | **思考计入 `max_tokens`**；≥1024 时自动留 1/4 给答案（answer_room）；`reasoning_budget_tokens` 可硬顶 | 默认 `MAX_TOKENS=128` 全被思考吃掉的风险 → 建议 `PROBE_MAX_TOKENS ≥ 256` |
| 投机解码 | MTP 草稿层（`--spec N --mtp`）；无 `--mtp` 也可 serve（后缀/前缀查找草稿）；`/metrics` 有 draft/accepted 计数 | `spec.decode` cap 可声明；per-request 投机指标（vLLM `chunk.metrics`）无 → `obs.per-request-metrics` 不声明 |
| 并发 | **默认单请求串行**；`--parallel N` / 配置 `"parallel"` 开多槽 | `CONCURRENCY>1` 时吞吐解释要谨慎；报告注记 |
| 上下文 | `--context` 8K–262K；超限**拒绝**（不静默截断）；`fit_max_tokens` 自动缩短 `max_tokens` | `PROBE_PROMPT_TOKENS` 与模板 `MAX_MODEL_LEN` 语义对齐到 `--context` |
| 首读延迟 | 长 prompt 首次全量读取 **~1 分钟 / 30K tokens**（前缀缓存后续秒级） | `PROBE_TIMEOUT` 建议 ≥1800；suite 首场景要预热 |
| KV 档 | `--kv int8`（默认）\| `q4_0` \| `k8v4`；`--kv-resident N`、`--kv-streaming` | 模板注释里给组合示例 |

## 8. `STRATA_*` 主要环境变量与引擎参数（模板 `EXTRA_ENGINE_ARGS`/`EXTRA_ENV` 素材）

* 引擎参数（`strata-<model>.json` 的 `args`，或 setup/launch flag）：`--prefill auto`、`--context`、
  `--kv`、`--kv-resident`、`--spec N --mtp`、`--draft-vocab`、`--mmap-experts`/`--resident-experts`、
  `--low-ram resident|mmap`、`--gpus`、`--adapt-every`、`--adapt-async 1`、`--pcie-frac`、
  `--parallel N`、`--pipeline-windows`、`--conversation-cache-mib`、`--resident-budget-gib`、
  `--vision off|gpu|cpu`、`--short-read`、`--prompt-cache 0`、`--adapt-swaps 0`、`--vram-reserve-mib`。
* 环境变量（`env` 块）：`STRATA_PF_FUSED`、`STRATA_QSA_CLUSTER`、`STRATA_ARGMAX_MULTI`、
  `STRATA_IQ_MT_MIN=1`（贪心可复现，A/B 必备）、`STRATA_SPEC_COUPLED`/`STRATA_SPEC_GUMBEL`、
  `STRATA_RAM_ADAPT`、`STRATA_EXCHANGE_ROTATE`、`STRATA_PIN_BY_NEED`、`STRATA_ARENA_PIN_GIB`、
  `STRATA_ARENA_MMAP`、`STRATA_IO_PREFETCH`、`STRATA_NAN_GUARD`、`STRATA_KV_HOST_REGISTER`、
  `STRATA_RESIDENT_HEADROOM_GIB`、`STRATA_PIN_RESERVE_MIB`。
* **A/B 可复现组合**（上游实测结论）：`STRATA_IQ_MT_MIN=1` + `--prompt-cache 0 --adapt-swaps 0
  --pcie-frac 0`（代价是 decode 变慢，仅对比实验用）——值得写进引擎模板注释。

## 9. 探针兼容性坑位汇总（→ 施工图任务来源）

1. `/metrics` 默认 JSON：抓取与就绪轮询都要 `?format=prometheus`（T2.1 profile 字段 + T3.1）。
2. 无 `vllm:cache_config_info`：就绪正则必须换（T2.1 `ENGINE_READY_METRIC`）。
3. 无 `/v1/completions`：completions 探测拒绝（T2.1 caps）。
4. 无逐 step 日志/stat logger 插件/torch profiler/图模式：`PROBE_LEVEL` 降级与报告注记（F1 caps 门禁自动生效 + F3 文案）。
5. 思考吃 `max_tokens`、首读慢、默认串行：压测参数建议进模板注释（T2.2）。
6. 版本探测命令（`strata --version`?）、`strata launch --port` 支持、进程形态：**上游文档未完全确认** → T2.5 真机核对清单。
7. 消费级 PC / Windows 常态：优先走 `deploy/external-probe.sh` 只读探测（T2.4 指南）；Linux NVIDIA/AMD 机器才用 host 模板拉起。
8. docker：上游无官方镜像承诺（仅 INSTALL.md 提及 Docker 一词，未核实）→ 本期 `RUNTIME=docker` die（红线 3）。
9. 厂商层正交：遥测（nvidia-smi/amd-smi/xpu-smi）继续按 `VENDOR` 走；Strata 自带 `strata:gpu_*` 指标可作为遥测旁路（F3 可选，不替代 SMI）。
